# Learning Lab

Keep the application runnable as one local Flask process with local assets.
Use English in the learner interface. Practice data belongs in ignored instance/.

When changing scoring or review, read docs/learning-rules.txt. Resolve product
policy ambiguities with the instructor; inspect code for implementation facts.

For a feature change, demonstrate its browser behavior and run the relevant
Python checks. Python line coverage does not establish frontend correctness.
When continuing another session, read docs/handoff.txt and inspect Git state.
