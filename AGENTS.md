# Learning Lab

Keep the application runnable as one local Flask process with local assets.
Use English in the learner interface. Practice data belongs in ignored instance/.

For existing behavior, read docs/learning-rules.txt and inspect the application.
For a new feature, use learner-confirmed decisions in workshop/decisions.txt;
resolve open product choices with the learner. Investigation is the agent's job.
Instructor examples are opt-in references, separate from the learner's decisions.

Use one complete, independently checkable behavior per implementation task.
Verify against the agreed examples, demonstrate the browser interaction and
record evidence. Python coverage measures backend execution only.
When resuming, read workshop/handoff.txt if present and inspect Git state.
