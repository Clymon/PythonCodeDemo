---
name: lab-handoff
description: Prepare a compact next-task handoff preserving decisions, current evidence and the next action when work needs a fresh context or another collaborator.
---

Use this when a new task, colleague or tool needs a portable project record.
Continue the current session when that better preserves useful reasoning.

1. Establish the purpose of the next task and inspect Git state and existing
   workshop artifacts. Reference the spec, decisions, tasks and evidence instead
   of duplicating them. Preserve reasons that are not already written elsewhere.
2. Write workshop/handoff.txt using templates/handoff.txt: current state, relevant
   decisions, known gaps, next action and the Skill that fits it. Keep credentials
   and personal data out of the record.
3. Give the next task one clear entry point. Ask it to restate the important
   constraints and selected action before editing. Correct discrepancies before
   treating the handoff as successful.

Complete when the intended recipient can reconstruct the required decisions
and next action from the handoff and its references. Writing a file alone is
not evidence that a fresh task understood it.
