# Save and reopen one lesson

**Blocked by** — None.

Add a Save lesson action to the lesson reader and a Saved lessons destination in learner navigation. Link each saved title back to the existing lesson.

**Pass when** — Save a completed lesson, leave it, refresh Saved lessons, and use the saved title to reopen it. It is still completed and its score has not changed. The entry belongs to the original browser profile and appears once.
