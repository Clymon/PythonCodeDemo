# Saved lessons

A learner wants to find lessons they intend to revisit. Learners decide what to save and can return to a saved lesson from any course.

## Agreed behavior

A learner can save any existing lesson, including a completed lesson. Saved lessons lists only that browser profile’s choices. Selecting an item opens its original course and lesson. The choice survives a refresh and a server restart.

## Verification

Save a completed lesson and refresh. Reopen it from Saved lessons and check that its reading status and score match the values before saving. Use a second browser profile to check whose list changes. Saving twice should leave one entry.

## Later decisions

Removal and filtering by course are separate tasks. The first ticket adds a way to save and reopen lessons.
