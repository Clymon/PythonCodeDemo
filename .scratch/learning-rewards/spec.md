# Learning rewards

A learner earns 10 points on first completion of each enrolled lesson. Reading completion can occur without a quiz answer. Undoing completion retains the award. Existing completed lessons receive one award when upgrading.

A learner can spend 10 points on one First Steps badge. A repeat redemption returns the existing badge. Insufficient points leave the wallet untouched. Quiz scores and other profiles are independent. Further badges and a leaderboard are outside this example.
