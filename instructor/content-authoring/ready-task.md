# C01: a teacher updates lesson text and a learner reads it

**What it delivers:** teacher edits an existing lesson, previews without saving,
saves valid text, then a learner reads it using the existing course/lesson route.
**Blocked by:** none after the example scope and behavior are confirmed.
**Acceptance:** valid save changes learner text; preview alone does not; invalid
save preserves previous text; stable IDs, attached content and learning records
remain; saved text survives server restart with the same database.

Prepared instructor task. Student participants approve their own task boundaries.
