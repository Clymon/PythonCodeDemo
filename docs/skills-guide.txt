CLASSROOM SKILLS — reusable methods for working with an agent

lab-discuss    Open idea -> confirmed human decisions and examples.
lab-plan       Confirmed decisions -> spec and approved complete tasks.
lab-implement  One approved task -> working behavior and verification evidence.
lab-review     Task result -> evidence mapping and human acceptance decision.
lab-handoff    Current artifacts -> a usable next-task entry point when needed.

Use a Skill when its situation fits. Small clear requests can be implemented
without a long planning chain. The first greeting change is deliberately simple.
The feature exercise uses discussion and planning because its policy is open.

Human responsibilities: state purpose, decide trade-offs, confirm scope and
examples, judge task boundaries and accept evidence. Agent responsibilities:
investigate project facts, propose options, implement, test and explain gaps.

These are original classroom adaptations informed by Matt Pocock's engineering
workflows, not copies of paid course text. Skill installation, selection and
invocation depend on the installed WorkBuddy client. Use the verified procedure
in docs/workbuddy-rehearsal.txt once the instructor trial has recorded it.
An explicit request to read SKILL.md is a fallback, not automatic discovery.
