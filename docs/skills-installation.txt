CHECK ACTUAL LOADING

load of the original named Skill, report its source, then stop before its workflow.
Inspect the actual Load skill activity and project path. Recorded 5.8.4 evidence
shows to-tickets loaded from the project even when absent from the slash picker.
That observation does not establish every newly added method's runtime behavior.
Check docs/workbuddy-rehearsal.txt for exact observed methods and limitations.

CONFIGURE A NEW PROJECT
File installation and project workflow configuration are separate steps.
Original setup-matt-pocock-skills explores the project, discusses tracker choices,
presents intended edits and waits for confirmation before writing. The classroom
clone already has AGENTS.md and docs/agents/ configured for a local Markdown
tracker under .scratch/. Inspect and reuse them. Run setup for a project that
needs configuration; do not rerun it just to reproduce a classroom screenshot.
