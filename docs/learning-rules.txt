LEARNING LAB — current behavior

One browser profile represents one anonymous learner. No names or real records.
The server owns the answer keys, scoring and persistent attempts.
An invalid option records nothing. A valid answer appends an attempt.
Only the first quiz attempt per question contributes to the original score.
Reading completion is a separate learner-controlled marker, not a grade.
Progress survives refresh and server restart with the same browser cookie.

These describe existing behavior. New review policy is a design decision:
read docs/client-brief.txt, discuss it with the learner and record the confirmed
choices in workshop/decisions.txt. Reasonable alternatives may be explored.
Explain any proposed change to an existing rule and obtain a deliberate decision.
The instructor reference illustrates one solution; it does not choose for you.
