WORKSHOP PRACTICE

1. Try the app. Browse the Course catalog from My learning. Open Designing
   Learning Activities, read its syllabus and enroll. Select Start learning,
   then open the second lesson. Answer a question and mark the lesson complete.
   Return to My learning. After a refresh, Continue learning reopens the same
   lesson. Check the completion record and first-attempt score in My progress.

2. Ask WorkBuddy: What does this repository do? What can I try in the app?
   Follow up: Does the app remember completed lessons after I refresh?
   Look for a file read or a tool result that supports the answer.

3. Watch the instructor discuss “I’d like to find the lessons I want to revisit.”
   Choose that wish, lesson search, progress after a retry, or your own idea.
   Select /grill-me and discuss the behavior you want. Record one decision and
   one item to postpone. Let the Agent find the technical facts.

4. Select /to-spec to collect confirmed decisions. Ask /to-tickets to propose
   an order with one verifiable result per ticket. Choose a task ready to start.
   Keep its path under .scratch/ and one observable acceptance condition.

5. After the break select /implement and reference your ticket. Follow the
   Agent's changes, checks and review. Try the result when it is ready.

6. Show the decision, one observed result, and what to do next. If the Agent
   is still working, report its last completed action. Use /handoff for a new
   session when you need to resume.
