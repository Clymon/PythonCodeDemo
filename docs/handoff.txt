HANDOFF FOR A FRESH AGENT

Use original handoff when context portability helps. Preserve the human's choices,
why they matter, the approved spec/current task, branch, evidence and next action.
Reference existing artifacts instead of copying them. The method writes its portable
record in the OS temporary directory and suggests the next Skills.

A fresh recipient should explain: what teaching problem are we solving; which
content/visibility choices were approved; what works now; what remains; and what
would count as completion? Check its explanation before allowing edits.
Main's optional reference is text editing with immediate visibility, not a default
policy for the class. Old review-feature run records describe the earlier product.
