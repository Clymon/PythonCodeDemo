EXPLORING AN UNFAMILIAR PROJECT

Open the student folder in WorkBuddy Code. Ask in one session:

1. What does this repository do? What can I try in the app?
2. Does Learning Lab remember which lessons I completed after I refresh?
3. Optional web search: How does Moodle show students which activities they
   have completed? Link the official guide.

Expand an activity in WorkBuddy. Which file did it read? What did that file
help it explain? A later question can investigate a feature you want to add.
